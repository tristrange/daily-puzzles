# Advanced lessons roadmap

Prioritize useful advanced lessons across the existing logic games before adding
another puzzle family. Rules pages explain how to play. Learn should teach players
to combine constraints, recognize patterns and solve harder positions.

## Delivery order

Each course or course revision is a separate, playable pull request. Revisit this
order after play-testing the preceding course.

| Order | Game | Teaching direction |
| --- | --- | --- |
| 1 | Trio | Combine quotas and no-three restrictions, carry deductions through links, and chain candidate eliminations. |
| 2 | Star Battle | Strengthen the current course around group reservations and interacting capacities. The simpler exercises remain introductions, not the advanced endpoint. |
| 3 | Nurikabe | Island reachability, forced expansion and sea connectivity, with several constraints contributing to a deduction. |
| 4 | Train Tracks | Combine line counts, track connectivity and restrictions on branches or closed loops. |
| 5 | Tents | Overlapping tree possibilities, matching constraints and line arrangements. |
| 6 | Queens | Region and line reservations that require looking across several groups. |
| 7 | Sudoku | Extend the current course beyond X-wing. Preserve existing exercise IDs and completion. |

These are teaching directions, not claims that a particular technique or course is
already implemented. Word Paths stays outside this deduction-focused curriculum.

## Course acceptance

- Order techniques from less involved to more involved reasoning. Do not use a
  larger board or a longer explanation as evidence that a lesson is advanced.
- Provide three to five varied exercises per technique. Start with one guided
  example, then ask the player to find the pattern in practice positions.
- Keep target and support highlights optional during unassisted practice. State
  the task clearly and accept other deductions that satisfy it.
- Teach candidate eliminations as useful progress, including deductions that do
  not immediately place a piece or symbol.
- Explain the actual premises and their connection in a short sequence. Avoid
  repeated rule text and unrelated steps.
- Certify prepared positions and reasoning. Agreement with a complete answer is
  insufficient evidence that the advertised technique works.
- Save lesson completion separately from daily progress, timers, stats and
  leaderboards. Preserve existing course progress when adding material.

Prefer a smaller polished course to a larger collection of rulebook drills.
Play-testing determines whether the examples teach useful recognition skills.
